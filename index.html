01 — Trabajo

Productos de Chúuk

Cada uno empezó con un problema de negocio concreto. Aquí está el problema, lo que construí y lo que cambió.

Validado · FECI 2025

AgriTech

Agricultura de precisión con IA que corre en el campo, sin internet.

  • FastAPI
  • YOLOv8n
  • Edge computing
  • IoT offline
Problema
La detección tardía de plagas causa pérdidas de más del 30 %, sobre todo en zonas rurales sin red.
Solución
Migré todo a procesamiento local: un servidor asíncrono y un modelo YOLOv8n que corren en hardware comercial directamente en la parcela.
Impacto
Pasó de prototipo a herramienta lista para campo: métricas críticas sin latencia de red. Despliegue en parcelas reales en 2026.
B2B · Salud

LabSnap

Sistema de gestión de laboratorio (LIS) para más de 22 tipos de estudios clínicos.

Diseñé la arquitectura y el esquema relacional. Hoy lidero la integración de cálculos bioquímicos en tiempo real junto a ingenieros de Adaca Medical. El proyecto aseguró inversión corporativa inicial.

  • Laravel
  • Vue
  • PostgreSQL
  • Tailwind
IA · Laboratorio

MicroOV

Análisis microscópico en tiempo real, guiado por IA.

YOLOv8 detecta automáticamente y un asistente con GPT-4 guía al personal no experto. El análisis pasa de minutos a segundos y un analista junior puede hacer el trabajo de un senior.

  • FastAPI
  • YOLOv8
  • GPT-4
  • JavaScript
Logística

Smart-FIFO

Inventario con rotación FIFO garantizada, códigos QR y mapa del almacén.

El sistema elige el lote correcto y guía el despacho en un mapa visual. Elimina mermas por caducidad y reduce errores humanos.

  • FastAPI
  • Python
  • MySQL
  • QR
Multiplataforma

CellyApp

Una base de código para escritorio y Android.

Construida sobre Chromium (la misma idea que Discord): núcleo y UI compartidos, empaquetados de forma nativa. Las funciones nuevas llegan a ambas plataformas a la vez.

  • TypeScript
  • Chromium
  • Android
  • Desktop

02 — Open source

Herramientas pequeñas, decisiones explicadas

Cada repo documenta el porqué de sus decisiones de arquitectura, no solo el cómo.

Ares-AMF / eco_fastapi_template

Plantilla de microservicios de bajo consumo. Serialización con orjson (Rust), uvloop, compresión equilibrada y rate limiting.

Python ↗ Ares-AMF / vanilla_fetcher

Cliente HTTP de menos de 2 KB. Backoff exponencial, caché con TTL y modo ahorro de datos del navegador.

JavaScript ↗ Ares-AMF / disk-audit-cli

Auditor de disco en paralelo con multiprocessing y os.scandir. Encuentra node_modules, venvs y builds olvidados.

03 — Sobre mí

Ingeniero con mente de artesano

Estudio Ingeniería en Sistemas Computacionales y soy CTO de Chúuk. Me interesa el punto donde el software se encuentra con la biología: plagas en un cultivo, células en un microscopio, muestras en un laboratorio.

Trabajo con lo que llamo libertad estructurada: autonomía para encontrar la mejor solución, dentro de un propósito claro y revisiones constantes. Me importa que el producto final se vea y se sienta pulido, no solo que funcione.

Fuera del teclado dibujo, escribo y escucho mucha música. Tengo certificaciones de Cisco Networking Academy y Fundación Carlos Slim.
