02Proyectos destacados

Problemas reales, productos reales

Toca cada tarjeta para ver el problema, lo que construí y el impacto.

Problema

Más del 30 % de pérdidas por detección tardía de plagas, sobre todo en zonas rurales sin red ni internet.

Solución

Migré todo a edge computing: un servidor asíncrono con FastAPI y un modelo YOLOv8n que corren en hardware comercial, directo en la parcela.

Impacto

Dejó de ser prototipo: métricas críticas sin latencia de red, con despliegue en parcelas del municipio planeado para 2026.

  • FastAPI
  • Python
  • YOLOv8n
  • Edge computing
  • IoT offline

Reto

Automatizar la captura de más de 22 tipos de estudios clínicos con trazabilidad, cálculos en tiempo real e integridad de datos médicos.

Solución

Dirigí la plataforma y el esquema relacional. Hoy lidero la integración de cálculos bioquímicos dinámicos junto a ingenieros de Adaca Medical.

Impacto

El rigor técnico aseguró una inversión corporativa inicial: arquitectura de grado empresarial.

  • Laravel
  • Vue.js
  • PostgreSQL
  • MySQL
  • TailwindCSS

Problema

El análisis microscópico es lento, caro y depende 100 % de un experto en sitio: un cuello de botella.

Solución

Plataforma web con YOLOv8 para detección automática y un asistente con GPT-4 que guía al personal no experto.

Impacto

El análisis pasa de minutos a segundos y un analista junior puede hacer el trabajo de un senior.

  • FastAPI
  • YOLOv8
  • GPT-4 API
  • JavaScript
  • TailwindCSS

Problema

Una mala rotación de inventario genera mermas por caducidad y eleva los costos de almacenamiento.

Solución

El sistema garantiza la rotación FIFO: identifica el lote correcto y guía el despacho con un mapa visual del almacén.

Impacto

Elimina mermas por caducidad y reduce errores humanos en toda la operación logística.

  • FastAPI
  • Python
  • JavaScript
  • MySQL
  • QR

Problema

Mantener bases de código separadas para escritorio y Android duplica tiempos, costos y fragmenta la interfaz.

Solución

Una app sobre Chromium (la misma idea que Discord): núcleo y UI compartidos, empaquetados de forma nativa para cada plataforma.

Impacto

Las funciones nuevas llegan a escritorio y Android a la vez, con una experiencia uniforme y mucho menos mantenimiento.

  • TypeScript
  • JavaScript
  • Chromium
  • Android
  • Desktop

04Ingeniería & open source

Herramientas que hacen el software más eficiente

Eco-FastAPI Template

Microservicios de bajo consumo: serialización con orjson (Rust), uvloop, compresión equilibrada y rate limiting.

Python · FastAPI · Docker

Vanilla Fetcher

Cliente HTTP de menos de 2 KB con backoff exponencial, caché con TTL y detección del modo ahorro de datos.

JavaScript · Cero dependencias

Disk Audit CLI

Auditor de disco en paralelo con multiprocessing y os.scandir. Encuentra node_modules, venvs y builds olvidados.

Python · Multiprocessing
